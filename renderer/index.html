API 接入、默认参数与本地数据

API 接入

可以添加多个 API（VoxCPM2、千问 CosyVoice 或兼容接口），在合成页底部的模型按钮里随时切换；密钥仅保存在本机。

添加 API
VoxCPM2 填到根地址（:8015）；千问填到 /api/v1。粘贴完整路径时程序会自动截取。
VoxCPM2 Key 形如 vx-…；千问 Key 形如 sk-…。

默认参数

VoxCPM2 固定 48 kHz 输出；千问可按模型支持的采样率选择。
